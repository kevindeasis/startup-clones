# startup-clones

Daily AI-startup clones, one folder per day: `YYYY-MM-DD-companyname/`.

## Git identity (required)
Every commit in this repository must be authored and committed as:

    git config user.name "Kevin De Asis"
    git config user.email "deasis@ualberta.ca"

Never use any other email (in particular not a gmail address). Set this before committing, in every fresh session.

## Conventions
- Each clone lives in its own folder with `SPEC.md`, `BUILD_PROMPT.md`, `BUILD_LOG.md`, `README.md`.
- Never commit `node_modules`, virtualenvs, build output, databases or `.env` files.
- Folder links use https://github.com/kevindeasis/startup-clones/tree/main/<folder>.
